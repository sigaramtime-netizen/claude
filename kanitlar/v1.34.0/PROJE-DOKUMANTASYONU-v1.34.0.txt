1) PROJE ÖZETİ
────────────────────────────────────────────────────────────────────────────────
Proje     : Brn Teknoloji ERP (İşletme Yönetim Sistemi)
Dil       : Python 3 (stdlib: http.server/wsgiref + sqlite3 — harici framework YOK)
Veritabanı: SQLite (data/erp.db) — 65 tablo
Web       : wsgiref tabanlı basit HTTP sunucu, port 8080, host 0.0.0.0
Şablon    : Jinja2 benzeri kendi render katmanı (core.py içinde)
UI Dili   : Türkçe
Kurulum   : pip gerektirmez (sadece Python stdlib). Playwright SADECE ekran
            görüntüsü almak için kullanılır (opsiyonel, çalışma zamanı değil).

TEMEL MİMARİ KURALLAR (proje genelinde geçerli):
  - K1  : Çoklu şirket izolasyonu — tüm veri tablolarında sirket_id; her sorgu
          aktif şirkete göre süzülür (sessionler.sirket_id).
  - Tek DB + sirket_id (İstek 3, Seçenek A). Şirket geçişi /sirket/gec.
  - Rota kaydı import ile yapılır: her modül `from core import route` kullanarak
    `@route(r"/yol", methods=(...), roles=(...))` ile kaydolur.
  - Yetki matrisi: rol bazlı (Admin, Muhasebe, Satis, Servis, Depo).
  - Audit: her kritik işlem audit_log tablosuna yazılır.
  - Belge numaraları: şirket başına bağımsız sayaç (db.sonraki_belge_no).
